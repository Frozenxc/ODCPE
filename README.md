# ODCPE Connect

ODCPE Connect is a Jio AirFiber **ODU (Outdoor Unit)** management and provisioning app. It is intended for authorized owners and technicians managing compatible Jio AirFiber equipment.

## Download

See the [v3.0.05 release](../../releases/tag/v3.0.05) for the APK and verified unpacking bundle.

## App

- Package: `com.odcpe.connect`
- Version name: `1.0.47`
- Build label: `V3_005`
- Minimum SDK: 24
- Target/compile SDK: 35

## Contents

The release includes the original APK and a verified unpacking bundle containing raw APK contents, Apktool-decoded resources/manifest/smali, JADX-readable sources, logs, and verification data.
